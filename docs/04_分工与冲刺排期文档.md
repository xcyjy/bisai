# 分工与冲刺排期文档

> 团队规模：2 人。技术栈：Python 后端 + Vue 前端。
> 本文给出角色划分、任务清单、协作约定与时间排期。**排期为相对时段，请按你们的实际截止时间压缩/拉伸。**

---

## 一、角色划分（2 人）

按"前后端 + AI/产品"自然切成两摊，**界面清晰、依赖最少**。

### 👤 成员 A —— 后端 / AI 工程师（"管线负责人"）
**核心职责**：把"小说→合法YAML"这条核心链路跑通。
- 设计/实现 **pydantic 剧本模型**（Schema 落地）。
- 实现转换 **pipeline**（分章 → 切场 → 抽取 → 逐场转换 → 校验 → YAML）。
- **Prompt 工程**：写转换 Prompt、few-shot、参照字典注入、重试逻辑。
- FastAPI 接口：`/convert`、`/result`、`/save`、`/export`。
- 校验与一致性检查、错误兜底。
- 准备评估数据（切场/对白准确率抽样）。

### 👤 成员 B —— 前端 / 产品（"体验负责人"）
**核心职责**：把剧本"可编辑、可打磨"做出来，撑起 demo 效果。
- 搭 **Vue 3 + Vite** 工程。
- 上传/粘贴小说页、转换进度页。
- **双栏编辑器**：左原文、右剧本（结构化卡片可编辑 / Monaco YAML 视图）。
- 导出 YAML、下载。
- 对接后端 API。
- 主导**文档收尾**（Schema文档定稿、README）、**demo 视频**、UI 美化。

### 🤝 两人共担（必须先一起做）
- **P0：Schema 定稿 + 接口契约**（最关键，先做，否则两边白干）。
- P2 联调；P3 整体打磨与提交。

> 💡 这样分工的好处：A 不碰前端、B 不碰 LLM，靠 **Schema + API 契约**这层"接口"解耦，可以**真正并行**开发，互不阻塞。

## 三、关键协作约定

### 3.1 接口契约先行（最重要）
- **第一件事**：两人一起把 **Schema（文档②）和 API 请求/响应 JSON** 敲定，写进 `S2`。
- 之后 B 用**mock JSON**就能独立开发前端，A 用 **CLI**就能独立验证后端，**最后才联调**。

### 3.2 Git 协作
- 建仓库，分支：`main`（可运行）+ `feat/backend`（A）+ `feat/frontend`（B）。
- 目录建议：
  ```
  /backend   (Python: pipeline, api, schema.py)
  /frontend  (Vue)
  /docs      (本套文档)
  /samples   (demo 小说)
  README.md
  ```
- **6/7 23:59 前可私有；6/8 00:00 起必须公开。**

### 3.3 沟通节奏
- 开工同步一次（确认契约）、中段同步一次（核心链路是否通）、收尾同步（联调+提交）。

## 四、冲刺排期（相对时段，按实际截止压缩）

> 下表以"总工期"拆成 4 个阶段，标注**并行**关系。若只剩 1 天，把每阶段时长按比例压缩；若有 2-3 天，可加做加分项。

| 阶段 | 时长占比 | A（后端/AI） | B（前端/产品） | 里程碑 |
|------|---------|-------------|---------------|--------|
| **P0 契约** | ~10% | 共同：定 Schema + API 契约 + 选好 demo 小说 | | ✅ 契约冻结 |
| **P1 并行开发** | ~40% | A1–A7、A9：**CLI 跑通"小说→YAML"** | B1–B5：前端骨架 + 编辑器布局（mock 数据） | ✅ 后端能出合法YAML；前端界面能点 |
| **P2 联调** | ~30% | A8 接口 + 配合联调 | B6–B8：编辑器接真实 API、导出 | ✅ **端到端跑通**（达标线） |
| **P3 打磨+交付** | ~20% | Prompt 调优、A10 评估、兜底 | B9–B10：UI、README、Schema定稿、**demo视频** | ✅ 提交 + 仓库公开 + 报名 |

### 三个"保命检查点"
1. **P1 结束**：A 必须能在命令行把一篇≥3章小说转成**合法 YAML**。做不到就先停下来调，别往后走。
2. **P2 结束**：浏览器里能完成"上传→转换→看到剧本→编辑→导出"。这是**达标线**，到这就有完整作品了。
3. **P3**：所有加分项都是"锦上添花"，**时间不够就砍**，优先保证交付物齐全（工具+Schema文档+视频+公开仓库）。
