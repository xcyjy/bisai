## 已拍板的关键决策

1. **剧本类型**：✅ **已定为竖屏微短剧（short_drama）**，集中做深短剧一条线，不做影视/短剧双方向。见文档③第二节。
2. **Schema 定稿**：✅ 见文档②第六节"已定稿决策"（短剧分集纳入核心，locations/source_ref 列为 Roadmap）。
3. **LLM 选型**：Claude（强）vs 国产模型（省）。
4. **加分项取舍**：原文对照高亮 / Fountain导出 / 分集时间轴，哪些进 MVP。
5. **分工确认**：文档④的 A/B 角色是否按你俩擅长方向对调。

## 最重要的两条原则

- ⭐ **契约先行**：先一起定死 Schema + API，再分头并行开发。
- ⭐ **保命链路**：优先保证"小说→合法YAML"跑通（达标线），编辑器和加分项往后排。
