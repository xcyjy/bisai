## 明天讨论要拍板的几件事

1. **剧本类型**：通用影视（保守稳）vs 微短剧（亮点高风险）→ 见文档③第二节优劣分析。建议：MVP 做通用影视，微短剧作"可扩展"亮点讲。
2. **Schema 定稿**：文档②第六节的"待讨论项"逐条确认。
3. **LLM 选型**：Claude（强）vs 国产模型（省）。
4. **加分项取舍**：原文对照高亮 / Fountain导出 / 质量指标，哪些进 MVP。
5. **分工确认**：文档④的 A/B 角色是否按你俩擅长方向对调。

## 最重要的两条原则

- ⭐ **契约先行**：先一起定死 Schema + API，再分头并行开发。
- ⭐ **保命链路**：优先保证"小说→合法YAML"跑通（达标线），编辑器和加分项往后排。
